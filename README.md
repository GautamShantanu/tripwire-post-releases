# tripwire post — downloads

Built artefacts for the tripwire post. **Binaries only — no source.**

The post is the software that runs on a computer at a shop: it records the
till camera onto that machine, works out when something happened at the
counter, and sends tripwire a short verdict. Video stays on that machine.

Each release carries one file per platform and a `.sha256` beside it. Check
the release notes for what to do about the unsigned warnings your operating
system will show.

You need a pairing code from a tripwire hub for any of this to be useful.
